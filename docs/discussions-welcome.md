# GitHub Discussions — welcome

Thanks for joining **AgentDoctor**.

AgentDoctor is a local CLI that audits AI coding agent configuration in repositories — instructions, ignore rules, permissions, and MCP setup — without an API key and without uploading your code by default.

## Useful links

- [README](https://github.com/pranee54/AgentDoctor#readme) — quick start
- [docs/rules.md](https://github.com/pranee54/AgentDoctor/blob/main/docs/rules.md) — stable rule IDs
- [ROADMAP.md](https://github.com/pranee54/AgentDoctor/blob/main/ROADMAP.md) — what’s next
- [CONTRIBUTING.md](https://github.com/pranee54/AgentDoctor/blob/main/CONTRIBUTING.md) — how to help
- [SECURITY.md](https://github.com/pranee54/AgentDoctor/blob/main/SECURITY.md) — private vulnerability reports

## How to use Discussions

- **Q&A** — usage questions and “is this expected?”
- **Ideas** — adapter, rule, and UX proposals
- **Show and tell** — CI integrations and team workflows
- **General** — everything else

Security reports belong in [Security Advisories](https://github.com/pranee54/AgentDoctor/security/advisories/new), not public issues or discussions.
